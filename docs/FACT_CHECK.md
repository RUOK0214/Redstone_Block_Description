# 정보 확인 기록

대상은 Minecraft Java 26.2, 기본 게임 틱 속도입니다. 2026-10-31에 한국어·영어 설명과 새 수량표·보충 정보를 검토했습니다.

## 근거

- 공식 Minecraft 26.2 클라이언트의 블록 상태·레지스트리와 동작 코드를 기준으로 수치를 확인했습니다.
- `src/gametest/java/io/github/ruok0214/redstonehelp/MechanicsChecks.java`는 별도 게임 월드에서 새 설명의 주요 수치를 검사합니다.
- `ExpandedMechanicsChecks.java`는 수량표와 추가 블록의 출력을 게임의 실제 계산과 비교합니다. `CatalogAudit.java`는 비교기 출력 블록과 발사기 동작 레지스트리를 조사합니다.
- 구리 블록의 산화 단계에 따른 트럼펫 음색은 [공식 Java 26.1 변경 기록](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)에서 추가된 기능이며, 26.2 게임의 악기 레지스트리와 직접 대조했습니다.
- 선반의 교환 동작은 [공식 Copper Age 변경 기록](https://feedback.minecraft.net/hc/en-us/articles/39966147272589-Minecraft-Java-Edition-1-21-9-The-Copper-Age), 돌풍구의 블록 조작은 [공식 1.21 변경 기록](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21), 크리킹 심장의 거리 출력은 [공식 1.21.2 변경 기록](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-2)과 해당 26.2 클래스의 동작을 대조했습니다.

호퍼 전송의 8게임 틱 대기, 감지체의 10게임 틱 재사용 대기와 레일의 같은 종류 연결 조건은 해당 게임 클래스의 동작 코드에서도 확인했습니다.
발사기의 등록 동작뿐 아니라 장착 가능 아이템·생성 알·유황 큐브 먹이 태그에 대한 기본 분기까지 확인했습니다.
표는 최대 묶음 크기가 같은 아이템으로 채운 경우입니다. 서로 다른 묶음 크기의 아이템이 섞이면 칸별 채움 비율이 필요하며, 수량표 하나로 합산하지 않습니다.
일반 보관함 계산과 달리 선반·조각된 책장·벌집·케이크 등의 고유 출력에는 이 수량표를 붙이지 않습니다.
모든 회로·리소스 팩·다른 모드와의 조합을 검증한 것은 아닙니다. 사진은 고정된 상태 예시이며 1.8초 전환 주기가 실제 회로 지연 시간을 뜻하지 않습니다.

## 표현 검토

- 중계기 잠금은 다른 중계기·비교기의 **출력 방향이 옆면을 향한다**는 의미가 드러나게 수정했습니다.
- 호퍼의 출구를 항상 아래로 해석할 수 있는 표현을 수정했습니다.
- 구리 전구는 전원을 끊어도 현재 켜짐·꺼짐 상태를 유지한다는 점을 분명히 했습니다.
- 소리 블록의 위 공간과 머리 블록의 소리 조건을 구체화했습니다.
- 게임 내 한국어 이름에 맞춰 동력 레일이라는 표현을 사용했습니다.
- 상자·통 등 보관함, 덫 상자, 독서대, 퇴비통, 주크박스의 기존 summary/detail 문장은 한국어·영어 모두 유지했습니다. 사진과 사진 설명, 추가 정보만 변경했습니다.
