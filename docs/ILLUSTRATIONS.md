# 인게임 사진 제작 기록

촬영 대상: Minecraft Java 26.2, 기본 리소스 팩, Fabric 테스트 클라이언트.

## 원본과 재촬영

- 원본 파일: `src/main/resources/assets/redstone_help/textures/guide/<주제>/<번호>.png`
- 촬영 코드: `src/gametest/java/io/github/ruok0214/redstonehelp/IllustrationCapture.java`
- 사진·상태 설명 연결: `src/client/java/io/github/ruok0214/redstonehelp/Illustrations.java`
- 해상도: 640×360, PNG. HUD·채팅 숨김, 고정 시점 촬영.

```powershell
.\gradlew.bat runClientGameTest -PcaptureIllustrations
```

촬영 결과는 `build/run/clientGameTest/illustration-captures`에 저장됩니다.
`-PcapturePreview`를 추가하면 가루·레버·피스톤만 먼저 촬영합니다.
테스트용 월드를 생성하며 사용자 게임 프로필이나 월드는 수정하지 않습니다.
촬영 명령은 게임 안에 블록·회로를 배치하고 전원·입력·시간을 변경합니다.
사진을 저장하기 전에 검증 대상 블록의 상태를 확인합니다.

## 상태 구성

- 전원 전환: 가루, 레버, 버튼, 압력판, 램프, 레일, 문, 다락문, 울타리 문.
- 세부 상태: 중계기 지연 설정, 비교/빼기 모드, 관측기 앞 블록 변경, 주야간, 호퍼 잠김.
- 이동 전후: 피스톤·끈끈이 피스톤·슬라임 블록·꿀 블록.
- 자동화: 발사기의 물 배치, 공급기의 아이템 배출, 제작기의 재료와 신호 입력.
- 유지 상태: 구리 전구의 소등·점등·전원 해제 후 점등 유지.
- 비교기 입력: 비어 있는/가득 찬 상자, 퇴비통의 빈/수확 가능 단계.
- 정지 이미지: 레드스톤 블록, 일반 레일, 덫 상자, 독서대, 피뢰침, 주크박스.

과녁의 짧은 신호는 `setblock`으로 실제 게임 블록 상태를 지정하고 틱을 멈춘 상태에서 촬영합니다.
스컬크 감지체는 게임의 감지 활성화 함수를 호출한 뒤 상태를 고정해 촬영합니다.
TNT는 점화된 엔티티를 정지한 상태로 촬영합니다. 이 장면은 반응의 상태를 보여 주며 실시간 영상이 아닙니다.
다른 장면도 캡처 순간에는 월드 틱을 정지해 흔들림 없이 상태를 기록합니다.

원본 PNG를 그대로 모드에 복사합니다. 이미지 속 블록이나 회로를 합성하지 않습니다.
게임 안에서는 이 사진을 비율에 맞춰 축소해 표시합니다.
87개 원본을 45개 사진 묶음으로 구성하며, 실과 철사 덫 갈고리는 같은 사진을 사용하므로 설명 주제는 46개입니다.

## 표시

여러 장인 사진은 1.8초마다 다음 장으로 바뀝니다. 전환은 실제 게임 틱 속도와 무관합니다.
다른 주제로 이동하거나 잠시 마우스를 벗어났다가 돌아오면 첫 장부터 시작합니다.
Shift를 놓으면 사진을 숨기고 기존 간단 설명을 표시합니다.
사용자가 설치한 리소스 팩의 외형이나 실제 월드의 블록 상태를 실시간 반영하지 않습니다.
