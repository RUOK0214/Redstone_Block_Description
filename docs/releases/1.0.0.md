# Redstone Block Description 1.0.0

인벤토리에서 레드스톤 관련 아이템의 기능, 작동 조건, 사진과 표를 읽는 Minecraft Java 26.2용 클라이언트 모드입니다.

## 이번 버전

- Mod Menu에 레드스톤과 도움말 책을 조합한 전용 아이콘을 추가했습니다.
- 한국어·영어 소개를 사용 방법, 설명 켜기·끄기, 수록 정보, 지원 환경으로 구분했습니다.
- Mod Menu에서 설명 번역을 켜면 게임 언어에 맞는 소개가 표시됩니다. 번역을 끄면 영어 소개가 표시됩니다.
- 기존의 233개 아이템, 71개 설명 주제, 실제 인게임 사진 190장과 수량표를 그대로 제공합니다.

## 사용 방법

아이템에 마우스를 올려 요약을 읽고, Shift를 누르면 사진과 상세 정보가 열립니다. 마우스 휠로 스크롤하고, 고정 키(기본 H)를 누르면 목차와 사진 조작을 사용할 수 있습니다. Esc로 고정 창을 닫습니다.

- 단축키 변경: 설정 → 조작 → 키 설정 → Redstone Block Description
- 설명 켜기·끄기: `/rbd on`, `/rbd off`
- 상태 전환·확인: `/rbd toggle`, `/rbd status`

## 설치

Minecraft Java **26.2**, Fabric Loader **0.19.5 이상**, Fabric API **0.160.0+26.2**, Java **25 이상**이 필요합니다.

`redstone-block-description-1.0.0.jar`를 게임 프로필의 `mods` 폴더에 넣으세요. 이전 Redstone Block Description 또는 Redstone Help JAR는 새 파일로 교체합니다. 서버 설치는 필요하지 않습니다. Mod Menu는 소개와 아이콘을 보기 위한 선택 사항입니다.

`SHA256SUMS.txt`에서 설치 파일의 SHA-256 값을 확인할 수 있습니다.

## English

Adds a dedicated redstone-and-guidebook icon and reorganizes the Korean and English Mod Menu description into controls, help commands, included references and requirements. Enable Mod Menu's description translation to follow the game language; the English metadata is used when translation is disabled.

Includes 233 vanilla items, 71 topics and 190 genuine in-game photos. Hover for a summary, hold Shift for details, scroll with the mouse wheel, and press the pin key (default H) for contents navigation and photo controls. Use `/rbd on|off|toggle|status` to manage help. Preferences are saved.

Requires Minecraft Java **26.2**, Fabric Loader **0.19.5+**, Fabric API **0.160.0+26.2** and Java **25+**. Client-only. Mod Menu is optional and is not bundled. Replace the older mod JAR with `redstone-block-description-1.0.0.jar`.
