# Redstone Block Description 0.9.0

Minecraft Java 26.2 / Fabric용 클라이언트 모드입니다. 인벤토리에서 아이템에 마우스를 올리면 블록의 기능과 작동 조건을 표시합니다.

233개 바닐라 아이템, 71개 설명 주제, 직접 촬영한 인게임 사진 190장을 포함합니다. Shift 상세 설명에서 사진·표를 스크롤하고, 창을 고정해 목차 이동과 사진 일시정지·이전·다음 기능을 사용할 수 있습니다.

## 이번 버전

- 설정 → 조작 → 키 설정 → **Redstone Block Description → 도움말 창 고정**에서 단축키를 변경할 수 있습니다. 기본값은 H이고, 키보드·마우스 지정과 초기화를 지원합니다.
- Shift 상세 설명이 표시될 때 지정한 키를 눌러 창을 고정합니다. Esc로 도움말만 닫습니다.
- `/rbd on`, `/rbd off`, `/rbd toggle`, `/rbd status`를 추가했습니다. `/rbd`는 사용법을 표시하며 `/redstonedescription`도 사용할 수 있습니다.
- 온·오프 상태를 저장합니다. 명령어는 내 화면에만 적용되며 서버 관리자 권한이 필요하지 않습니다.
- 모드 정보에 기능·사용법·지원 환경과 한국어·영어 소개를 추가했습니다.

## 설치

1. Minecraft Java **26.2**, Fabric Loader **0.19.5 이상**, Java **25 이상**을 준비합니다.
2. 아래의 **redstone-block-description-0.9.0.jar**와 **Fabric API 0.160.0+26.2**를 해당 게임 프로필의 `mods` 폴더에 넣습니다. Fabric API는 포함되어 있지 않습니다.
3. 이전 버전의 이 모드 파일은 새 파일로 교체합니다. 서버에는 설치하지 않습니다.

GitHub의 자동 ‘Source code’ 파일은 설치용이 아닙니다. `SHA256SUMS.txt`로 설치 JAR의 무결성을 확인할 수 있습니다.

## 검증

빌드와 실제 클라이언트 게임 검증을 통과했습니다. 단축키 변경·저장·초기화, 마우스 지정, 온·오프 명령어, 기존 인벤토리·사진·표 동작을 검사하고 화면 73장을 기록했습니다. 설명은 Java Edition의 기본 동작에 관한 안내입니다.

## English

A client-side Minecraft Java 26.2 / Fabric guide with factual inventory tooltips for 233 vanilla items, 71 topics and 190 real in-game photos. Hold Shift for scrollable details, comparator count tables, instruments, music-disc output and dispenser actions. Pin the guide to navigate its contents and control photo playback.

Version 0.9.0 adds a configurable pin key (default H) under **Options → Controls → Key Binds → Redstone Block Description**, plus client commands `/rbd on`, `off`, `toggle` and `status`. Preferences are saved; no server installation or administrator permissions are required. Korean and English descriptions are included.

Install **redstone-block-description-0.9.0.jar** alongside **Fabric API 0.160.0+26.2** in `mods`. Requires **Minecraft Java 26.2**, **Fabric Loader 0.19.5+** and **Java 25+**. Replace older copies of this mod. The source-code archives are not installable mods.
